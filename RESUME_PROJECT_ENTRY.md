## 🌐 Option 3: LinkedIn / Naukri / Portfolio Description Version

**Project Title:** SaaS Financial Reporting & Customer Churn Analytics Engine (AI-Assisted)  
**Technologies:** Python, Pandas, Scikit-Learn, ReportLab, Matplotlib, Pytest, GitHub Actions CI/CD  

**Summary:**  
Developed an automated Python-based financial analytics and customer churn modeling system designed to streamline periodic SaaS management reporting and customer retention workflows.

**Key Highlights & Capabilities:**
- **Financial Analytics & Unit Economics:** Automated data ingestion and calculation of Monthly Recurring Revenue (MRR), Annual Recurring Revenue (ARR), Month-over-Month growth, Customer Acquisition Cost (CAC), and customer base roll-forwards.
- **Cash Flow Ledger & Forecasting:** Modeled historical operating cash flows across multiple expense lines and built an ordinary least squares (OLS) linear trend engine to project 6-month forward cash positions and burn rates.
- **Predictive Churn Modeling:** Built an isolated customer-level machine learning pipeline using Logistic Regression with scikit-learn `ColumnTransformer` to score accounts by churn probability and categorize them into actionable risk tiers for proactive retention.
- **Automated Investor PDF & Visualizations:** Automated generation of multi-page executive PDF reports and 12 high-resolution analytical charts using ReportLab and Matplotlib.
- **Quality & Reliability:** Engineered a decoupled orchestration layer with severity-aware error handling, automated directory creation, artifact validation, and 180 automated unit and regression tests integrated with GitHub Actions CI/CD across Python 3.9–3.12.

*Note: Developed using an AI-assisted engineering approach (ChatGPT, Claude Code, Antigravity) with a focus on business logic validation, robust pipeline architecture, and comprehensive testing.*
